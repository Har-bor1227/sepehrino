# Fartak Tasking — Employee mobile-first redesign (v2)

این بسته شامل دو پوشه با ساختار اصلی پروژه است:

- `employee/` مسیرهای پنل کارمند، layout و استایل اختصاصی
- `components/` کامپوننت‌های ارسالی شما؛ فایل‌های تغییر نکرده نیز حفظ شده‌اند.

## نصب در پروژه اصلی

1. از پروژه یک نسخه پشتیبان بگیرید.
2. محتوای `employee/` را در **همان مسیری که اکنون پوشه employee پروژه Next.js قرار دارد** جایگزین کنید (مثلاً `app/employee` یا `app/(panel)/employee`؛ این ZIP از جای دقیق آن در سورس اصلی اطلاعی ندارد).
3. محتوای `components/` را در پوشه `components/` پروژه merge کنید. فایل‌های مشترک admin و سایر بخش‌ها از ZIP ورودی بدون تغییر حفظ شده‌اند.
4. کدهای `lib/`, خدمات داده، session, server actions و مدل‌های پایگاه داده تغییر نکرده‌اند.
5. در پروژه کامل `npm install` / `npm run build` و سپس تست عملی روی دستگاه‌های موبایل را اجرا کنید.

## تغییرهای جدید (فراتر از نسخه اول)

- داشبورد: کارت‌های وظایف قابل باز کردن و برای تسک معمولی کنترل تغییر وضعیت مستقیم؛ برای تسک تکراری ساده دکمه انجام نوبت امروز؛ برای تسک مرحله‌ای لینک به جزئیات.
- داشبورد: نوار پیشرفت مبتنی بر داده‌های تسک و نمایش بصری ساده‌تر وضعیت‌ها.
- موبایل: ناوبری پایین دارای active state و badge اعلان، جست‌وجوی سریع در header؛ منوی کناری دارای Escape و جلوگیری از اسکرول پس‌زمینه هنگام باز بودن.
- موبایل: تسک‌ها به صورت کارت یک‌ستونی و فشرده؛ انتخاب‌گر native وضعیت برای لمس آسان، و dropdown دسکتاپ با قابلیت Escape.
- منوی تغییر وضعیت: رفع مشکل clipping با حذف overflow محدودکننده کارت‌ها و بخش مربوطه.
- واکنش‌گرایی: فیلدها، کارت‌ها، نوار ناوبری، safe-area موبایل، کنترل‌های حضور و غیاب، focus-visible و کاهش حرکت.
- جست‌وجو: label قابل دسترسی افزوده شد.

## تست‌های انجام‌شده

- بررسی اسکریپتی سینتکس **تمام 44 فایل TSX** در این بسته با ترنسپایلر TypeScript — بدون خطای نحوی.
- بررسی ساختار فایل‌ها و یکپارچگی ZIP.

## محدودیت تست

این بسته **تمام پروژه Next.js نیست**: `package.json`, `tsconfig.json`, کدهای `lib`, schema پایگاه داده، استایل‌های global و سرور فراهم نشده‌اند. بنابراین type-check کامل، اجرای مرورگر، تست واقعی backend و عملکرد سرور اکشن‌ها **در این محیط انجام نشده است**. مسیرها و importهای موجود در ورودی بدون دستکاری در business logic نگه داشته شده‌اند. پس از merge، تست عملکردی (فیلتر، تغییر وضعیت، تکمیل مرحله، اعلان، حضور و غیاب، ورود) را حتماً انجام دهید.

این یک تغییر UI/UX و ترکیب فایل‌های ارائه‌شده است؛ فایل‌های غیرمرتبط عمداً بازنویسی نشده‌اند.
